# Hello World

A minimal React Native app built with Expo. It displays **Hello World!** on Android.

## Run on Android

1. Install [Expo Go](https://expo.dev/go) on an Android device.
2. Install the project dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm start
   ```

4. Scan the QR code with Expo Go.

If an Android emulator and Android SDK are installed, you can instead run:

```sh
npm run android
```
